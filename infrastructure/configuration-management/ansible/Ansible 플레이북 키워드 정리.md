# Ansible 플레이북 키워드 정리

## 개요

Ansible로 인프라 관리를 준비하며 플레이북의 선언, 작업 실행, 파일 관리와 동기화 키워드를 정리합니다.

## 학습 내용

### 플레이 선언 키워드

| 키워드 | 의미와 메모 |
| --- | --- |
| `name` | 플레이북이나 작업의 이름이며 실행 로그에 표시<br>기존 작성 순서에서는 가장 처음에 선언한 항목 |
| `hosts` | 인벤토리에서 이 플레이북을 실행할 대상 호스트나 그룹을 지정 |
| `become` | 다른 사용자 권한으로 실행할지 지정하며 false는 접속 계정을 사용한다는 의미 |
| `vars` | 이 플레이북에서 사용할 변수를 정의<br>한 파일에 모아서 관리할 수도 있으며, 장단점을 고려해야 함 |

### 작업 실행 및 파일 관리 키워드

| 키워드 | 의미와 메모 |
| --- | --- |
| `tasks` | 위에서 아래 순서로 실행할 작업 목록 |
| `command` | 셸 해석 없이 대상 서버에서 명령을 실행 |
| `argv` | 명령과 인수를 목록으로 전달해 공백이나 특수문자의 오해석 경감 |
| `delegate_to` | 해당 작업만 지정한 호스트에서 실행<br>자주 사용하는 옵션 |
| `changed_when` | 작업을 변경으로 표시할 조건이며 false는 조회나 검사에 사용 |
| `file` | 디렉터리 생성이나 파일 권한 등 파일 시스템 상태를 관리 |
| `path` | file 모듈이 관리할 파일이나 디렉터리 경로 |
| `state` | file 모듈이 유지할 상태이며 directory는 디렉터리 존재를 보장 |
| `mode` | 파일이나 디렉터리의 접근 권한을 지정 |
| `copy` | 실행 제어 서버의 파일을 대상 서버로 복사 |
| `src` | 복사하거나 동기화할 원본 경로 |
| `dest` | 복사하거나 동기화할 대상 경로 |
| `no_log` | 해당 작업 결과를 로그에서 가려 비밀값 노출을 경감 |

### 파일 동기화 키워드

| 키워드 | 의미와 메모 |
| --- | --- |
| `synchronize` | rsync를 사용해 파일이나 디렉터리를 동기화 |
| `recursive` | 하위 디렉터리까지 포함해 동기화할지 지정 |
| `rsync_opts` | 제외 경로 등 rsync에 전달할 추가 옵션 |

## 정리

- 플레이 대상과 변수를 정의하는 키워드, 개별 작업에 사용하는 키워드를 구분합니다.
- 파일 복사와 rsync 동기화에 사용하는 옵션을 구분해 참고합니다.
